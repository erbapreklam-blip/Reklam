# ReklamHesap v2

C# / .NET 8 Windows Forms + SQLite.

Bu sürümde:
- Folyo ürünleri tanımlı.
- Laminasyon ana başlığı altında Laminasyonlu ve Laminasyonsuz bağımsız fiyatlar var.
- Folyo m² hesabı ve fiyatı otomatik bağlandı.
- Fiyat Yönetimi ekranından ürün fiyatları değiştirilebilir.
- Ek Hizmet Fiyatları ekranında Yemek, Servis KM Gidiş-Dönüş, İskele, Merdiven, Vinç ve Cam Kirli fiyatları tutulur.
- Veriler `%LOCALAPPDATA%\\ReklamHesap\\reklam_hesap.db` dosyasında yerel tutulur.

Çalıştırmak için Visual Studio'da `ReklamHesap.csproj` açın ve çalıştırın.
